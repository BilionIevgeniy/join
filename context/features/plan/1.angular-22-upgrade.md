# 1. Angular 22 and TypeScript 6

## Why

- The app runs Angular 21.2 with TypeScript 5.9. Angular 22 (released 2026-06-03) made Signal Forms, `resource()`/`httpResource()` and Angular Aria stable and OnPush the default change detection; NgRx 22 (needed in feature 5) targets Angular 22
- Angular 22 requires TypeScript 6.0 (`>=6.0 <6.1`) and Node ≥ 22; TypeScript 6 changes defaults and deprecates options
- Interview angle: "How do you upgrade an Angular app across majors?", "What changed from 17 to 22?"

## Scope

1. `.nvmrc` with the Node LTS the Angular 22 docs name (≥ 22), `engines` in `package.json`
2. `ng update @angular/core@22 @angular/cli@22` on the branch; commit the result of each schematic separately so the migrations are reviewable; read the update guide (angular.dev/update-guide, 21 → 22) and list in the PR which migrations ran
3. TypeScript 6: fix new errors and deprecations in `tsconfig*.json` (no `ignoreDeprecations` unless a dependency forces it, with a comment)
4. Update the other dependencies to versions that support Angular 22 / TS 6 (`@supabase/supabase-js`, `vitest`, `jsdom`, `typedoc` until feature 2 removes it, `viewerjs`)
5. If `ng update` adds `ChangeDetectionStrategy.Eager` to components, **leave it** (feature 5 removes it behind the smoke tests) and say so in the PR
6. Remove `provideHttpClient()` (no `HttpClient` is used; ADR 0001)

## Non-goals

Any refactor, OnPush clean-up, new APIs (Signal Forms, `resource()`), lint setup.

## Acceptance criteria

- `ng version` shows 22.x and TypeScript 6.0.x; `npm ci && npm run build && npm run test` green (no new warnings besides the known budget warnings)
- Manual smoke check: login, guest, board drag and drop, add/edit task with image, contacts CRUD

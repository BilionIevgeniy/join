    Class AddTaskComponent

    AddTaskComponent — create/edit form for a task.

    Used both as a standalone page (AddTaskPage) and inside the app-wide modal (opened via ModalService for the "add task" / "edit task" flows). Emits save with a ready-to-persist DTO; the caller owns actually calling TaskService.
